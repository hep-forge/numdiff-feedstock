[![Anaconda Platforms](https://anaconda.org/hep-forge/numdiff/badges/platforms.svg)](https://anaconda.org/hep-forge/numdiff)

Feedstock for [numdiff](https://www.nongnu.org/numdiff/) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

Numeric-aware diff tool for comparing files with small numeric differences

## Architectures

| Architecture | Latest published |
|--------------|------------------|
| linux-amd64 (`linux-64`) | ✅ `5.9.0` |
| linux-arm64 (`linux-aarch64`) | ✅ `5.9.0` |

_As of the last feedstock render; the badges above are live._


## Install

```bash
conda install -c hep-forge -c conda-forge numdiff
```
